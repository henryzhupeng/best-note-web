# 优记 BestNote · Web v7.20

这是一个可直接在浏览器打开的高保真交互网页版，覆盖产品需求文档中的 MVP 核心路径：

- 批量上传最多 20 张图片，自动推荐学习、工作、兴趣、会议、健身、阅读、项目、旅行、食谱或投资模板
- 独立 OCR 与批量图片 AI 整理都使用真实 OCR
- 批量图片会按识别正文生成相关标题、标签、段落、列表和表格
- 模板不再返回固定占位内容，所有结构都由本次识别正文生成
- 独立图片转文字入口：真实 OCR、语言选择、逐图进度、置信度、编辑、复制与保存
- OCR 后处理：清理标点、异常空格和错误断行
- 删除状态栏、页码、平台按钮、水印、URL 和重复行等截图噪声
- 自动识别标题、键值对、列表、正文段落和表格，并生成对应的便签式结构
- 使用连续线条检测区分表格边框和文字行，避免文字行被误判为表格行
- 只保留位于表格区域内的行列线，过滤标题装饰线和正文边缘
- 表格会检测网格线、移除线条干扰，并逐个单元格进行 OCR
- 保留原图检测到的行列数和空白单元格，避免空单元格导致列错位
- 低置信度单元格会使用对比增强版本进行第二轮识别
- 自动识别失败时，可在便签预览中点击“识别为表格”强制按行列整理
- 识别后的表格保留表头和多列数据，在预览及保存后的笔记中渲染为表格样式
- 对规则表格效果最佳；复杂合并单元格、手写表格或低清截图仍建议人工核对
- 结果预览和笔记详情参考 Apple Notes 的白底、简洁字体和段落层级
- 过滤图形、图标、线条、符号碎片和低置信度文字，避免误识别为正文
- 根据全文领域强度和正文重点生成标题，少量无关词不会改变主标题
- 提供 3 个主题相关候选标题，支持修改、切换和重新生成
- 内置“使用示例图片”，可一键验证 OCR 是否正常工作
- 上传新截图时会自动替换上一批 OCR 图片，避免新旧截图混合识别
- 支持清空全部图片，识别处理中会锁定文件操作
- 每条笔记卡片提供置顶、合并和删除快捷操作，可切换“置顶 / 含表格”筛选
- 笔记列表支持文件夹筛选、多选合并，以及合并后自动将原笔记移入回收站
- 合并后的内容按原笔记标题分节，保留表格、列表和标签
- 笔记详情支持直接编辑表格，并可增加行、删除行、增加列、删除列
- 右上角回收站入口、删除数量角标、恢复、永久删除和一键清空
- 笔记列表、文件夹筛选、全文搜索、本地备份导入与导出
- 导出 Markdown、JSON、Excel 兼容表格（`.xls`）和纯文本
- 浏览器 IndexedDB 主存储 + localStorage 兜底，可安装为 PWA（手机主屏 / 桌面应用）
- 自动保存版本历史，可恢复误删、误改和错误的表格调整
- 表格支持合并单元格、取消合并和撤销/重做
- 支持手机拍照、相册和剪贴板截图快捷导入
- 内置 8 条真实示例笔记和可视化自检页

方式二：启动一个本地静态服务器后访问：

```bash
ruby -run -e httpd . -p 4173
```

然后打开 `http://localhost:4173`。

> 页面本身不需要打包工具；首次 OCR 会从 jsDelivr 加载 Tesseract.js 引擎和语言模型。

## 当前限制

这是用于产品验证和交互演示的前端原型：

- 独立 OCR 已接入浏览器端 Tesseract.js，可读取图片真实文字
- 首次 OCR 需要联网下载识别引擎和语言模型，后续会由浏览器缓存
- 标题生成使用本地领域评分规则，不调用外部大模型
- 图形过滤基于 OCR 置信度、文字占比和区域类型，极复杂图片仍建议人工核对
- 批量图片整理使用本地规则完成语义分块；接入大模型后可以进一步提升摘要和合并质量
- 图片仅在当前浏览器会话中预览，刷新页面后需要重新选择
- 笔记保存在当前浏览器的 IndexedDB，不会跨设备同步；可用 JSON 备份迁移
- `.xls` 导出为 Excel 可直接打开的 HTML 表格，不是原生 XLSX

## 接入真实服务

当前网页已经包含真实 OCR。若希望获得更高精度，或者希望批量 AI 整理也使用真实模型，可替换以下入口：

- `runOcrRecognition()`：独立 OCR，默认使用浏览器端 Tesseract
- `runAiOrganize()`：先对批量图片做真实 OCR，再通过 `buildGeneratedNote()` 生成内容
- 如需更强语义合并，可将 `runAiOrganize()` 中得到的 OCR 文字上传到大模型服务

建议真实云服务后端提供两个统一接口：

```text
POST /api/ocr
输入：多张图片
输出：每张图片的文字、置信度、页面顺序（云 OCR 场景）

POST /api/notes/organize
输入：OCR 结果 + 模板类型
输出：标题、摘要、结构化内容、标签建议
```

生产版本还应补充：账号与权限、云端同步、图片压缩、超时重试、文件类型白名单、接口限流和错误监控。

## PaddleOCR 高精度 OCR Skill

已在本机 Codex 中安装以下两个 Skill，下次会话可用：

- `paddleocr-text-recognition`
  - 适合普通文字、CJK、小字号和截图文字识别。
  - 返回文字、检测框和置信度。
- `paddleocr-doc-parsing`
  - 适合复杂版面、表格、公式、图表、多栏文档和阅读顺序恢复。
  - 表格可以提供单元格级结构。

网页保留浏览器端 Tesseract 作为本地和回退模式。高精度模式需要服务端 API，Token 不能安全地放进前端页面。

如果后续启用高精度模式，建议采用下面的结构：

```text
浏览器
  -> 本机/服务器后端 /api/ocr/high-precision
  -> PaddleOCR OCR 或 layout-parsing API
  -> 后端统一转换 Markdown / 表格 JSON
  -> 返回网页
```

启动高精度模式：

```bash
cd /Users/pengzhu/Documents/Codex/2026-09-27/ni-k/outputs/best-note-web
PADDLEOCR_DOC_PARSING_API_URL="$PADDLEOCR_DOC_PARSING_API_URL" \
PADDLEOCR_ACCESS_TOKEN="$PADDLEOCR_ACCESS_TOKEN" \
PORT=4175 ruby server.rb
```
然后打开 `http://localhost:4175`，在页面中选择“高精度 PaddleOCR”。

需要安全配置的环境变量：

```text
PADDLEOCR_ACCESS_TOKEN
PADDLEOCR_OCR_API_URL
PADDLEOCR_DOC_PARSING_API_URL
```

不要把 Token 写进 `app.js`、网页 HTML、压缩包或 Git 仓库。

如果暂时没有 PaddleOCR 凭证，可以直接使用“本地 Tesseract”模式，高精度模式失败后会自动回退到本地模式。

PaddleOCR 文档解析适合优先应用的场景：

- 复杂表格和单元格识别
- 财务报表、发票和统计表
- 多栏文档、长截图和扫描件
- 公式、图表和版面阅读顺序恢复
- 需要根据文字置信度标记低可信区域

- 模板扩展为 10 个领域模板，并加入“智能推荐”自动判断

- 首页改为更轻的入口式布局，减少介绍性内容占比
- OCR 与批量 AI 都改为“识别 → 直接编辑标题/标签/正文 → 最后保存”
- AI 结构化升级为核心入口，支持课堂笔记、错题、技术文档、阅读摘录和会议纪要模板
- 支持直接粘贴苹果备忘录、豆包、Kimi、ChatGPT 等外部 OCR / AI 文字
- 支持浅色/深色主题、自动保存状态和 Ctrl/Cmd+N/S/F 快捷键
- 新增优记双栏工作台：左侧文件夹分组和笔记拖拽排序，右侧富文本/Markdown 编辑器
- 顶部六边形对勾 Logo，主色调整为 #4070F4，移动端自适应
- 笔记正文、长 OCR 文本和宽表格限制在便签纸内部，避免横向溢出
- 支持创建自定义文件夹，并在笔记详情、OCR 保存和 AI 保存时选择文件夹
- 表格支持单元格编辑、增删行列、合并/取消合并、撤销/重做
- IndexedDB 主存储和自动版本历史，可恢复误删、误改或错误调整
- 笔记支持置顶、文件夹筛选、含表格筛选、章节排序、JSON 备份和版本恢复
- 示例中心内置 8 条可直接导入的真实内容笔记
- 支持手机拍照、相册多选和剪贴板截图快捷导入
- 保存识别笔记时归档原始截图，笔记卡片和详情页可查看缩略图、点击放大并保存原图
- 新增 `self-check.html`、PWA manifest、Service Worker 和安装入口

## 产品路线 A

BestNote 不和苹果备忘录比 OCR 精度。苹果便签擅长图片文字原样提取，BestNote 专注把任意来源的文字加工成课堂笔记、错题、参数表、阅读摘要或会议行动项。图片 OCR 保留为基础输入入口，不再作为核心卖点。

## 手机打开方式

当前本地服务器默认监听 `0.0.0.0`，同一 Wi-Fi 下手机可以访问：

1. 在 Mac 上启动服务：`PORT=4175 ruby server.rb`
2. 查看 Mac 局域网 IP：系统设置 → 网络 → Wi-Fi → 详细信息
3. 手机浏览器打开：`http://Mac的局域网IP:4175`
4. 点击页面中的“安装到手机 / 桌面”，或使用浏览器“添加到主屏幕”
5. 安装后可以从微信、相册等应用通过系统分享菜单发送截图到“优记”

> 如果 PWA 安装入口没有出现，通常是浏览器要求 HTTPS 或 `localhost`。iPhone 可用 Safari 的“添加到主屏幕”；Android Chrome 可用菜单中的“安装应用”。

## 文件夹怎么用

1. 打开左侧“全部笔记”。
2. 点击右上角“＋ 新建文件夹”。
3. 输入名称，例如“客户会议”“健身计划”或“旅行资料”。
4. 打开优记，在标签右侧的“文件夹”下拉框中选择目标文件夹，再点击“保存修改”。
5. OCR 和批量 AI 保存前可以点文件夹旁的“新建”，直接创建并选中，不会丢失当前草稿。

自定义文件夹会写入 IndexedDB，并包含在 JSON 备份中。
